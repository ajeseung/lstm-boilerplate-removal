# LSTM 기반 다국어 웹페이지 본문 추출 및 Android 앱

**웹페이지의 광고·메뉴·헤더·푸터 등 비본문 영역을 제외하고 본문 텍스트를 추출하는 AI 모델과 Android 애플리케이션 개발 프로젝트**

- **기간:** 2023.02–2023.10
- **구분:** 한양대학교 컴퓨터소프트웨어학부 졸업 팀 프로젝트
- **개인 담당:** HTML 데이터 수집·전처리, 모델 변환·연동, Android 앱 개발
- **사용 기술:** Python, BeautifulSoup, LSTM, TensorFlow, PyTorch, Java, Android Studio

## 1. 프로젝트 개요

하나의 웹페이지에는 실제 본문뿐 아니라 메뉴, 광고, 사이드바, 헤더, 푸터 등이 함께 포함됩니다. 이러한 요소를 구분하지 않고 텍스트를 수집하면 불필요한 정보가 섞일 수 있습니다.

이 프로젝트에서는 웹페이지의 HTML에서 본문과 비본문 영역을 구분하는 **LSTM 기반 Boilerplate Removal** 모델을 활용하고, 추출 결과를 사용자가 확인할 수 있는 Android 애플리케이션을 개발했습니다.

## 2. 주요 기능 및 처리 흐름

```text
HTML 데이터 수집
        |
        v
데이터 전처리 및 영역 구분용 라벨링
        |
        v
LSTM 기반 본문 / 비본문 추정
        |
        v
본문 텍스트 추출
        |
        v
Android 앱에서 결과 확인
```

- **데이터 처리:** 다국어 웹페이지 HTML 수집 및 학습 데이터 구성
- **본문 추출:** 본문과 비본문 영역을 구분하는 모델 활용
- **사용자 인터페이스:** HTML 입력 후 본문 영역 추출 결과를 확인하는 Android 앱 구현

## 3. 내가 담당한 역할

### HTML 데이터 수집과 전처리

- BeautifulSoup를 활용해 한국어·영어 등 여러 언어의 웹페이지 HTML 데이터 수집
- 본문·비본문 영역을 구분하기 위한 라벨링 및 전처리 작업 참여

### 모델 활용을 위한 변환과 연동

- 학습된 모델을 애플리케이션과 연결할 수 있도록 변환 및 연동 작업 수행
- 입력 데이터에서 본문 영역만 추출하여 결과로 전달하는 흐름 구현

### Android 애플리케이션 개발

- Java·Android Studio 기반 애플리케이션 개발
- HTML 입력과 추출 결과 표시 기능 구현

## 5. 결과

- **테스트셋 기준 약 92% 정확도**: 당시 팀 프로젝트에서 보고한 모델 결과
- 모델의 추론 결과를 활용하는 Android 앱 구현
- 데이터 처리부터 모델 활용, 모바일 인터페이스 개발까지 연결한 경험

> 정확도 수치는 테스트셋 구성, 평가 지표 정의, 실험 조건을 확인한 뒤 더 구체적으로 명시하는 것이 좋습니다. 개인 성과와 팀 공동 성과는 구분해 기술했습니다.

## 6. 프로젝트를 통해 배운 점

모델 성능만으로 사용자에게 가치가 전달되지는 않았습니다. 웹페이지 HTML의 구조를 정리하고 추론 결과를 애플리케이션에서 활용하도록 연결하는 과정에서, **데이터·모델·사용자 인터페이스 간 통합**의 중요성을 경험했습니다.
